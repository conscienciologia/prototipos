Esta é a prática que fecha o curso: uma mudança pequena, de ponta a ponta — da sugestão ao site publicado.

## Ideias de mudança para começar

Escolha uma, pequena o bastante para fazer em poucos minutos:

- Corrigir um erro de português que você notar em alguma aula.
- Melhorar uma frase confusa, mantendo o sentido.
- Acrescentar um exemplo a mais numa lista já existente.
- Adicionar uma pergunta de reflexão no fim de uma aula.

Evite mudanças grandes por enquanto — o objetivo é ver o ciclo completo funcionando, não fazer a mudança perfeita.

Para não deixar isso abstrato: esta lista abaixo nasceu vazia, e ganhou a primeira linha quando este curso foi rascunhado — é exatamente o tipo de mudança pequena sugerida acima ("acrescentar um exemplo a mais numa lista já existente"), só que de verdade, não hipotética.

Quando você fizer esta atividade, uma opção simples é acrescentar seu próprio nome de autor admirado aqui — e ver a lista crescer no site publicado.

## Como aplicar

1. **Peça para a IA sugerir o texto** da mudança escolhida, apontando a aula e o trecho.
2. **Aplique via o link "Editar página"** (rodapé de qualquer aula) — ou, se a sua IA estiver conectada ao GitHub, peça para ela aplicar diretamente.
3. **Salve a mudança.** Se você não tiver permissão direta de escrita no repositório, o GitHub vai automaticamente te oferecer criar uma cópia (fork) e abrir um Pull Request — é só seguir os botões que aparecem na tela.

:::tip[]
Pull Request é só o nome do "pedido de mudança" no GitHub — alguém com permissão de escrita (hoje, o Eduardo) revisa e aprova antes de ir para o site publicado. Isso é o mesmo mecanismo de revisão que os cursos usam para o conteúdo em si.
:::

## Conferindo o resultado

Depois que a mudança for aceita, o site leva de 1 a 5 minutos para atualizar (é automático — [GitHub Actions](https://github.com/conscienciologia/prototipos/actions) reconstrói o site a cada mudança aceita).

Abra `conscienciologia.github.io/prototipos/` depois desse tempo e confira: a mudança que você pediu está lá?

## Se algo não funcionou

Sem problema — é exatamente para isso que esta área de prática existe. Anote o que travou (a IA não conseguiu, o editor confundiu, não achou o botão certo...) e traga para o grupo. Esse tipo de dificuldade é informação tão útil quanto a mudança em si.

Quando terminar aqui, a [Área 2](../03-area-2-protocolo/) sobe o nível de dificuldade: editar algo que aparece em mais de um lugar do repositório.
