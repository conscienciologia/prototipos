## O que é o GitHub, rapidamente

O GitHub é onde o conteúdo destes cursos vive de verdade — cada aula que você já leu é um arquivo lá. O site que você vê é gerado automaticamente a partir desses arquivos.

Ter uma conta no GitHub é o que permite sugerir uma mudança nesses arquivos — corrigir um erro, melhorar uma frase, acrescentar um exemplo — sem precisar pedir para ninguém fazer isso por você.

## Como criar a conta

1. Acesse [github.com/signup](https://github.com/signup).
2. Informe um e-mail, crie uma senha e escolha um nome de usuário.
3. Confirme o e-mail quando o GitHub pedir.

Não precisa de foto, bio ou nada além disso — uma conta simples já é suficiente para tudo que este curso propõe.

:::tip[]
Se você já tem uma conta no GitHub de algum uso anterior, pode usar a mesma — não precisa criar outra.
:::

## Depois de criar a conta: peça acesso à organização

Envie uma mensagem no grupo de WhatsApp com o seu nome de usuário do GitHub, pedindo pra alguém te adicionar à organização `conscienciologia` no GitHub.

Não é obrigatório para sugerir mudanças — o fluxo de fork + Pull Request (explicado na [Área 1](../02-area-1-alterar-frase/)) funciona sem isso. Mas ser membro da organização facilita: dá pra editar direto, sem passar pelo fork.

## Atividade

1. Crie a conta (ou confirme que já tem uma) e faça login em [github.com](https://github.com).
2. Mande a mensagem no grupo pedindo acesso à organização, com seu usuário.

É só isso por agora — a próxima aula usa essa conta.
