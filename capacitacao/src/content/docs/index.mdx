## Perguntas que este protótipo deveria provocar

Não é para aprovar a plataforma inteira. É para reagir a partes específicas:

- Esse tamanho de aula funciona?
- Faz sentido a ordem/nomenclatura conscienciológica como estrutura de navegação?
- Comentários por aula: queremos isso, e público?
- Vale a pena editar conteúdo direto no GitHub, ou o Google Docs continua sendo melhor para isso?
- Uma área de prática separada pra aprender GitHub faz sentido, ou isso deveria estar embutido nos cursos reais?
- Este site e o Moodle dos Colégios Invisíveis resolvem o mesmo problema, ou problemas diferentes?

Leve suas reações para o grupo — é para isso que o protótipo existe.
